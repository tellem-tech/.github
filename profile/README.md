Мы создаём **Tellem**, чтобы бизнесу было проще понимать своих клиентов и работать с **повторными продажами**. CRM объединяет клиентскую базу, маркетинг, лояльность и аналитику. Клиентское приложение помогает принимать заказы в браузере, а при подключённом боте — внутри Telegram.

## 🧩 Что умеет Tellem

| Задача | Возможности |
| --- | --- |
| **Понимать клиентов** | Карточки клиентов с историей заказов и бонусным счётом. [RFM-анализ](https://docs.tellem.tech/modules/crm/analytics/) группирует клиентов по давности, частоте и сумме покупок. |
| **Возвращать клиентов** | [Рассылки](https://docs.tellem.tech/modules/crm/mass-mailings/) сразу или по расписанию для одной точки — всем подписанным клиентам или выбранным RFM-группам. Telegram, VK и почта доступны при подключении канала и разрешении клиента. |
| **Развивать лояльность** | [Акции, промокоды и бонусы](https://docs.tellem.tech/modules/crm/marketing/) для следующих покупок. |
| **Оценивать результат** | [Аналитика](https://docs.tellem.tech/modules/crm/analytics/) продаж, повторных покупок и удержания клиентов, включая когортные отчёты. |
| **Принимать заказы** | [Клиентское приложение](https://docs.tellem.tech/modules/app/) с каталогом, корзиной и оплатой. Работает в браузере, а при подключённом боте — внутри Telegram. |
| **Подключать сервисы** | [Платёжные сервисы](https://docs.tellem.tech/modules/crm/payment-providers/), [Telegram и VK](https://docs.tellem.tech/modules/crm/integrations/), а также [iiko](https://docs.tellem.tech/modules/crm/iiko/) для передачи заказов в кассу. |

## 🚀 Познакомиться с продуктом

1. **Посмотреть глазами покупателя** — откройте [демонстрационный магазин](https://tellem.store/).
2. **Разобраться в возможностях** — изучите [обзор CRM](https://docs.tellem.tech/modules/crm/) и [чек-лист запуска](https://docs.tellem.tech/modules/crm/getting-started/).
3. **Обсудить подключение** — [напишите команде в Telegram](https://t.me/tellem_tech_bot). Регистрация и управление подпиской доступны в [личном кабинете](https://tellem.tech/lk).

Обновления и новости продукта — в [Telegram-канале Tellem](https://t.me/tellem_it).
